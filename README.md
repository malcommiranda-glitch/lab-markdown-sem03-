# Nombre del Proyecto
 
## Descripción
Este proyecto es una *aplicación web* diseñada para practicar
**Markdown** en documentación técnica.

## Instalación
Requisitos:
- Node.js 18 o superior
- Git
- Una cuenta de GitHub

Pasos:
1. Clonar el repositorio
2. Instalar las dependencias
3. Ejecutar el proyecto
